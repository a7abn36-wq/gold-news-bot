# ☁️ الطريقة 1 — GitHub Actions (المفضلة: مجاني 24/7)

الفكرة: GitHub بيصحّي البوت كل 5 دقايق على سيرفراتهم، البوت ينفذ شغله ويقفل. الحالة بتتحفظ في برانش `bot-state` في نفس الريبو، فالبوت مش بينسى الأخبار اللي نشرها.

## ✅ اللي محتاجه

1. حساب GitHub (مجاني) — github.com
2. توكن البوت من @BotFather (خطوة 1 في الجزء اللي تحت لو لسه معملتش البوت)
3. قناة تليجرام والبوت **أدمن** فيها بصلاحية النشر (خطوة 2 تحت)

## ⚠️ قاعدة ذهبية

> الريبو لازم يكون **Public** — ده شرط دقائق الـ Actions المجانية بلا حدود. ومفيش خطر: التوكن بيتحط في **Secrets** مشفرة مش في الملفات، والكود مفيهوش أي بيانات حساسة.

## الخطوات بالترتيب

### 1) ارفع ملفات المشروع للريبو
اعمل ريبو جديد **Public** وارفع كل ملفات المشروع (بما فيهم فولدر `.github` المخفي). لو الريبو فيه ملف workflow واحد زي `.github/workflows/bot.yml` يبقى تمام.

### 2) حط التوكن والقناة في Secrets 🔐
في الريبو: **Settings** → **Secrets and variables** → **Actions** → **New repository secret** — ضيف اتنين:

| الاسم (Name) | القيمة (Secret) |
|---|---|
| `TELEGRAM_TOKEN` | التوكن من @BotFather |
| `CHANNEL_ID` | `@اسم_قناتك` أو رقم الجروب |

### 3) شغّل أول تجربة 🚀
1. تاب **Actions** في الريبو → لو ظهرلك زرار تفعيل **"I understand my workflows, go ahead and enable them"** اضغطه
2. اختار **Gold News Bot** من القايمة الشمال → **Run workflow** → **Run workflow**
3. استنى دقيقة وافتح على التشغيل تشوف اللوج — لو القناة استقبلت رسايل يبقى **كل تمام!** 🎉
4. من هنا وبعد كده البوت شغال لوحده كل 5 دقايق

## ⏱️ إزاي بيشتغل بالظبط؟

| كل 5 دقايق البوت بيعمل | |
|---|---|
| 📥 يقرأ الأوامر اللي وصلت ويرد عليها | /news /gold /calendar /price /id /start |
| 🚨 يبعت تنبيه قبل الخبر الاقتصادي المهم بـ 30 دقيقة | أحداث USA عالية التأثير |
| 📰 كل 10 دقايق يجيب الأخبار الجديدة المهمة وينشرها مترجمة | مترشحة بالكلمات المفتاحية |
| 💾 يحفظ الحالة في برانش `bot-state` (كوميت واحد بيتحدث) | عشان مايعيدش نفس الخبر |

## ⚠️ حاجات لازم تعرفها (بصراحة كاملة)

1. **الأوامر مش فورية** — لو بعتت /price هيرد خلال 5-10 دقايق (في أول دورة بعد رسالتك). ده طبيعة النظام المجاني
2. **الجدولة تقريبية** — GitHub أحياناً يتأخر دقايق في تشغيل الدورة، خصوصاً أوقات الذروة. للتنبيهات (نافذة 30 دقيقة) ده مقبول جداً
3. **الترجمة من سيرفرات جيتهب** — أحياناً جوجل بيقيّدها لحظياً، فممكن خبر ييجي بنصه الإنجليزي. البوت بيكمّل عادي ومفيش حاجة بتقف
4. **لو البوت وقف بعد فترة طويلة** — GitHub بتوقف الجدولة في الريبوهات اللي مفيهاش نشاط 60 يوم. البوت ده بيعمل commit تلقائي كل شوية فده بيحميه، بس لو حصل: افتح Actions → Run workflow يدوي مرة ويرجع يشتغل
5. **متعدلش برانش `bot-state`** — ده ملف الحالة بتاع البوت، سيبه لحاله

## 🔧 حل مشاكل سريعة (نسخة جي هب)

| المشكلة | الحل |
|---|---|
| Actions مش بتشتغل خالص | اتأكد إن الريبو **Public** وإنك فعّلت الـ workflows من تاب Actions |
| التشغيل أخضر بس مفيش رسايل في القناة | راجع Secrets: الأسماء بالظبط `TELEGRAM_TOKEN` و `CHANNEL_ID` + البوت أدمن في القناة |
| رسالة "401 Unauthorized" في اللوج | التوكن غلط — هات توكن جديد من @BotFather بأمر /token وحدّث الـ Secret |
| رسائل مكررة | افتح تاب Actions وشوف آخر تشغيل — لو خطوة حفظ الحالة بتقع هتلاقي السبب في اللوج |
| عايز توقف البوت مؤقتاً | تاب Actions → Gold News Bot → ⋯ → **Disable workflow** |

# 📱 الطريقة 2 — Termux (الموبايل)

## الخطوة 1️⃣ — اعمل البوت بتاعك (دقيقتين)

1. افتح تليجرام ودوّر على **@BotFather** (اللي عليه علامة التوثيق ✅)
2. ابعتله: `/newbot`
3. هيسألك اسم البوت → اكتب أي اسم (مثلاً: `بوت أخبار الدهب`)
4. هيسألك اسم مستخدم للبوت → لازم ينتهي بـ `bot` (مثلاً: `gold_news_eg_bot`)
5. هيديك **توكن** شكله كده:
   ```
   7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   **انسخه واحفظه** — ده مفتاح البوت بتاعك

## الخطوة 2️⃣ — اعمل قناة وضيف البوت فيها

1. اعمل **قناة** جديدة في تليجرام (أو استخدم قناة عندك)
2. روح لإعدادات القناة → **Administrators** → **Add Admin** → ضيف البوت بتاعك
3. اعطيه صلاحية **Post Messages** (النشر)
4. **لو القناة عامة (لها لينك @username):** هتحط `@اسم_القناة` في الإعدادات تحت
5. **لو القناة خاصة:** اعمل جروب مؤقت، ضيف فيه البوت، اكتب `/id` في الجروب، البوت هيديك رقم الجروب — انسخه

## الخطوة 3️⃣ — نزّل Termux على الموبايل

⚠️ **مهم جداً:** نزّل Termux من **F-Droid** (f-droid.org) مش من Google Play — نسخة Google Play قديمة وبتبوظ.

## الخطوة 4️⃣ — التنصيب في Termux

افتح Termux واكتب الأوامر دي واحدة واحدة:

```bash
pkg update -y && pkg upgrade -y
pkg install python -y
pkg install tzdata -y
```

بعد كده حط ملفات البوت في الموبايل:
- انقل ملف الـ ZIP اللي نزلته لذاكرة الموبايل
- في Termux اكتب:

```bash
cd /sdcard/Download
unzip gold-news-bot.zip -d ~/
cd ~/gold-news-bot
pip install -r requirements.txt
```

## الخطوة 5️⃣ — ضبط البوت (أهم خطوة!)

افتح ملف الإعدادات:

```bash
nano config.py
```

عدّل سطرين بس:

```python
BOT_TOKEN = "7123456789:AAHxxxxxxxxxxxxxxx"   # التوكن بتاعك
CHANNEL_ID = "@اسم_قناتك"                      # أو الرقم اللي خدته من /id
```

- للحفظ والخروج من nano: اضغط `Ctrl+X` ثم `Y` ثم `Enter`

## الخطوة 6️⃣ — شغّل البوت 🚀

```bash
bash start.sh
```

لو شفت الرسالة دي يبقى تمام:
```
✅ البوت اشتغل! سيبه شغال عشان ينشر الأخبار
```

## 🔒 عشان البوت يفضل شغال 24 ساعة على الموبايل

1. **سطر `termux-wake-lock` موجود في start.sh** — بيمنع الموبايل ينوم التيرموكس
2. روح لإعدادات الموبايل → **Apps** → **Termux** → **Battery** → اختار **Unrestricted** (أو اقفل تحسين البطارية)
3. سيب الموبايل شاحن ولا البطارية هتخلص أسرع
4. لو قفلت Termux بالغلط، افتحه واكتب `bash start.sh` تاني

## 🕹️ الأوامر — كل واحد بيعمل إيه

| الأمر | الوظيفة |
|---|---|
| `/start` | ترحيب + شرح كل حاجة |
| `/news` | آخر الأخبار المهمة مترجمة |
| `/gold` | أخبار الدهب بس |
| `/calendar` | الأخبار الاقتصادية الجاية (النهاردة وبكرة) |

| `/id` | رقم أي جروب/قناة (للإعداد) |

## ⚙️ تعديلات اختيارية (كلها في config.py)

| الإعداد | الافتراضي | يعني إيه |
|---|---|---|
| `NEWS_CHECK_MINUTES` | 10 | كل كام دقيقة يجيب أخبار |
| `RELEVANCE_THRESHOLD` | 5 | درجة أهمية الخبر عشان يتنشر (زوّد الرقم = أخبار أقل وأهم) |
| `ALERT_BEFORE_MINUTES` | 30 | التنبيه قبل الخبر بكام دقيقة |
| `NEWS_MAX_PER_CYCLE` | 8 | أقصى أخبار تنشر في المرة |
